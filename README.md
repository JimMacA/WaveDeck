# WaveDeck
RP2350-based audio effects processor the size of a deck of poker cards.

<img width="4080" height="3072" alt="WD_Card" src="https://github.com/user-attachments/assets/778ab146-d163-4b86-8bb8-dfc54d70763b" />

Included:
RP2350 processor
16 MB flash
8 MB PSRAM
SD card slot with QSPI support
2 universal input channels support electric guitars, line inputs, piezo pickups.
TanH soft saturation on inputs eliminates digital clipping. 
Input Gain/Drive controls on thumbwheels.  Extra gain control on trimpots.
Built-in electret microphone.
Stereo outputs drive headphones or line level.  Output level controlled by thumbwheel.
For additional thumbwheel pots for parameter control.
4 general-purpose analog/digital inputs for pots or switches.
4 capacitive/proximity sensor channels for theremin-like control.
248 x 128 e-ink display
8 general-purpose tact switches
2 pressure-sensitive piezo sensors
1 AH LiPo battery lasts for hours.

Not Included:
Use case.
